# Security policy

## Reporting a vulnerability

Please email **hello@thesoloserviceprovider.com.au** with "Security" in the subject line. Include the steps to reproduce the problem and what you expected to happen. Please don't open a public issue for a security problem.

You'll get a reply within 7 days.

## Scope

Jarvis runs on your computer with your own Anthropic and GitHub credentials. It asks before every file edit, command, commit and push, blocks dangerous commands, and never pushes to the default branch or force-pushes. Reports about ways to bypass those protections, leak credentials or run commands without approval are especially welcome.
